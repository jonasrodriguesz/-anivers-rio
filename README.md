# Esse Est. — site de aniversário

Site estático responsivo feito com HTML, CSS e JavaScript puro.

## Como abrir no VS Code

1. Extraia o arquivo ZIP.
2. No VS Code, vá em **File > Open Folder** e selecione `esse-est-aniversario`.
3. Abra `index.html` no navegador. Recomendado: instalar a extensão **Live Server**, clicar com o botão direito em `index.html` e selecionar **Open with Live Server**.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `css/style.css`: cores, tipografia, layout e responsividade.
- `js/main.js`: comportamento do botão para abrir a carta.

## Personalização

A declaração foi mantida conforme o texto fornecido. Para trocar frases, edite os parágrafos dentro de `<div class="letter__copy">` em `index.html`.

As fontes Cormorant Garamond e DM Sans são carregadas pelo Google Fonts; se não houver internet, o site usa fontes alternativas instaladas no dispositivo.

## Publicar para compartilhar

Você pode publicar a pasta em um serviço de hospedagem de sites estáticos, como GitHub Pages ou Netlify. O link só ficará acessível para ela depois que você fizer a publicação.
